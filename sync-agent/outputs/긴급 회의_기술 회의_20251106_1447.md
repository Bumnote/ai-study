역할 분담

AI 전문가 “김성규” 님과의 대화 내용 정리

공통

• 파인 튜닝은 포기하셔야 한다. 시간이 너무 부족하다.

• 학습도 시간 안된다. 포기해야한다. 모델 가져와서 학습하고, 성능 확인하고 싸이클 5번만 돌려도 2주 순삭이다. 학습 데이터도 찾아야 하고, 크롤링도 하게 된다면 못할 것 같다.

• LLM은 gemini flash가 저렴하고 빠르다. ^_^ 

• 추후에 시간이 남는다면, stt 또는 tts 모델을 활용하는 기능을 넣고, 벤치마킹하면 좋은 서비스가 될 것 같다.

전처리 

• Langchain 활용해서 전처리를 담당하는 agent 형태로 만드는 건 괜찮은 것 같다.

• 뉴스가 주는 문제점 중 하나가 뉴스에 나오는 단어들 중 LLM이 모르는 단어가 있을 가능성이 있다.

채점 

• LLM 신뢰성 측면에서 문제가 될 수 있을 것 같다.

• 워드 임베딩 모델, 문장 임베딩 모델, LLM 다 사용하면 좋을 것 같다. 오픈소스 활용하면 금방 될 것이다.

• 단어별 유사도, 문장의 의미, LLM의 결과 요약하는 것까지 하면 될 듯 싶다.

추천 

• 추천 알고리즘은 1달 가지고는 안된다.

• 사용자 기반 추천 알고리즘이 아니라면 괜찮을텐데, 유사한 사용자와 비슷한 추천을 한다던가 등 사용자가 생기는 순간 바로 허들이 엄청 높아진다.

• 추천 알고리즘 종류가 3가지 정도 있는데, 3가지 모두 데이터를 수집해야 된다. 알고리즘 자체가 어려운 것은 아니지만, 사용자 기반 데이터를 활용해 추천하는 것 즉, 데이터 수집 부분이 어렵다.

• 사용자 기반이 아니라면 정렬 순, 혹은 랜덤일 것 같은데 어떻게 설계하느냐에 따라서 달라질 것 같다.
