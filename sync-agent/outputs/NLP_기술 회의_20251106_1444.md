spaCy

자연어 처리를 위한 python 라이브러리

특징

- 성능 및 확장성

- 사전 훈련된 모델

- 통합 파이프라인

- 사용자 정의 가능

- 풍부한 도구와 통합

설치

pip install spacy

언어별 모델 다운로드:

(영어) python -m spacy download en_core_web_sm

예제

```python
import spacy

# 영어 모델 로드
nlp = spacy.load("em_core_web_sm")

# 텍스트 샘플
text = "SpaCy is an excellent tool for NLP in Python"

# 텍스트 처리
doc = nlp(text)

# 토큰화 및 품사 태깅
for token in doc:
	print(token.text, token.pos_)
	
#개체명 인식
for ent in doc.ents:
	print(ent.text, ent.label_)
```
