공통

랜딩 페이지

• 가이드

• 랜딩 페이지에서는 로그인 페이지로만 이동할 수 있다. 

고객 기능

로그인/회원가입

• 소셜 로그인만 구현한다. → Kakao  Naver  Google

• 관리자 기능은 구현하지 않는다.

• 최초 로그인의 경우,  관심사 카테고리 설정 페이지와 테스트 여부를 선택할 수 있다.

• 로그인을 해야 메인 페이지를 볼 수 있다. 

메인 페이지

• 메인 페이지는 추천 기사만 보여준다.

• 뉴스 API

검색 페이지

• 정렬 기준 : 인기순, 최신순

• 기사 난이도

• 백엔드에서 기사 별로 읽었는지 안 읽었는지 여부도 함께 반환해야 한다.

좋아요한 뉴스 페이지

• 읽은 뉴스, 읽지 않은 뉴스 모두 좋아요 할 수 있다.

• 필터링(읽은 뉴스 확인)

• 정렬 기준 : 기본(좋아요한 순 - updateAt 내림차순)

마이 페이지

• 바로가기 목록

• 기사별 용량(byte수), 전체 용량(byte수)을 이용하여 usb로 대시보드를 만든다.

테스트 페이지

• 사용자는 처음 회원가입을 하면 테스트/처음부터 기능이 있다.

단어 페이지

• 사용자가 저장한 단어를 보여준다.

• 단어 레벨은 넣지 않는다. 

• 단어 뜻과 해당 단어가 들어간 기사(링크)와 문장을 보여준다.  

• 전체 / 공부 중인 단어(진행) / 이미 외운 단어(완료) → 3가지

• 정렬 기준 → 업데이트한 순서대로 정렬(updatedAt)

• 페이지네이션 → 무한 스크롤 기법을 적용한다.

기사 페이지

• 사용자는 기사의 문장들에 대해 해석한 것을 입력해야 한다.

• 사용자는 모르는 단어의 경우 클릭을 하면 단어를 보여준다.

• 사용자가 모르는 문장이 있으면 힌트를 눌렀을 때 형태소 분석을 한 내용을 보여준다.

• 사용자는 단어와 문장을 즐겨찾기할 수 있다. 

• 기사를 좋아요할 수 있다.

• 채점 버튼을 통해 사용자가 적은 내용들에 대해 채점을 한다.
