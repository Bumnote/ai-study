☑️ 1. 왜 만들려고 하는가?

✅ 1.1 문제 제기

• 개발자들은 매일 학습과 코딩 활동을 하지만, 이를 체계적으로 기록하지 못하고 그냥 흘려보내는 경우가 많다.

• TIL(오늘 배운 것) 문화가 확산되고 있음에도, 직접 작성해야 하는 번거로움과 꾸준히 기록하기 어려운 습관의 장벽 때문에 실제 작성 비율은 낮다.

• 그 결과, 개인은 자신의 학습 이력을 돌아보기 어렵고, 팀 단위로도 에러 해결 경험이나 학습 노하우가 공유되지 않아 지식 자산이 쌓이지 않는다.

✅ 1.2 문제 구체화 : 문제의 원인과 영향을 파악(Why → How)

• 왜 이런 문제가 발생했는가?

• 사용자(혹은 시장)는 이 문제 때문에 어떤 불편을 겪는가?

• 이 문제는 얼마나 자주/광범위하게 발생하는가?

✅ 1.3 기존의 대안 조사

• Notion, Obsidian, 블로그 작성

• WakaTime

• ActivityWatch

• GitHub Contributions

☑️ 2. 프로젝트의 목적 (Project Purpose)

본 프로젝트는 개발자의 일상적인 학습·코딩 활동을 자동으로 기록하고 요약하여 TIL(오늘 배운 것) 형태로 제공하는 플랫폼을 구축하는 것을 목적으로 한다.

이를 통해 개발자는 번거로운 수동 기록 없이도 자신의 성장 과정을 체계적으로 관리할 수 있고, 팀은 개별 경험이 집단 지식으로 축적되는 효과를 얻을 수 있다.

✅ 2.1 자동 기록 & 요약

• IDE, 터미널, 브라우저, Git 활동 로그를 자동으로 수집

• 하루 단위로 AI 요약을 생성 → “오늘 공부 요약(TIL)” 자동 작성

✅ 2.2 학습 회고 및 성장 추적

• 개인별 학습 히스토리를 시각화하여 성장 과정을 한눈에 확인

• 에러 해결 과정과 학습 성과를 재참조 가능

✅ 2.3 팀/조직 지식 공유

• 팀 단위 TIL 공유 보드 제공

• 동일한 문제의 반복 해결을 줄이고, 집단 지식 자산을 강화

✅ 2.4 생산성 향상

• 자동화된 기록으로 학습/개발 활동에만 집중할 수 있음

• 기록 누락을 줄이고 포트폴리오, 회고, 면접 준비 자료로 재활용 가능

☑️ 3. 시장 조사 및 경쟁 분석

✅ 3.1 해야 할 조사

• 유사 서비스 조사

• 경쟁사가 해결하지 못한 Pain Point 정리

✅ 3.2 경쟁사 비교 분석 (SWOT 분석)

• 강점 (Strength)

• 약점 (Weakness)

• 기회 (Opportunity)

• 위협 (Threat)

• 고객 인터뷰 또는 설문조사
