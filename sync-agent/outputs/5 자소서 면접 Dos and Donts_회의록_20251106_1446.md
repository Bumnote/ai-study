1. 회사는 너가 얼만나 간절한지… 관심 없음. 관심 있는 것은

• 우리(회사)에 필요한 역량이 있는지

• 우리랑 잘 맞을지(컬쳐핏)

• 조직에 도움이 될지(반대로 피해를 줄 지) → 가치관과 태도, 성격

• 너(지원자)가 회사에 어떤 가치를 줄 수 있는지

2. 경쟁, 상대평가, 모수

• 우리는 전체를 볼 수 없음(회사는 전체를 봄)

• 채용 인원은 정해져 있고, 많은 좋은 후보 중 가장 적합한 사람을 선택하기 마련

3. 피드백 없음

• 왜 떨어졌는지 알기 힘들어요.

• 가끔 피드백을 주기도… 감사히 받읍시다.

투자 대비 수익률 매우 낮음

• 투자한 시간은 보장받을 수 있나? 비례하나? → X

• 손실률 100%의 행진. 시간과 함께 깎여나가는 자존감

• 레버리지를 할 수 있다면? → 주변의 도움을 적극 활용하기

• 적당한 시간을 투자해야.

하루 8시간을 같이 보내야할 사람을 선택하는 것

• 신중할 수 밖에 없음(잘못 뽑으면 쟤 누가 뽑았냐 소리 나옴)

• 다른 역량이 뛰어나도 문제를 일으킬 것 같다면?

• 정규직 위주의 우리나라 채용 문화상 내보내기 힘듦 → 들어오기 힘들게 만들자!

보여줘야 할 것

• 준비성

• 진정성 : 해당 직무를 위해 어떤 노력을 했는가?

• 발전(성장) 가능성 : 학습 의지, 적극성, 피드백 수용, 부족함 인정, 경험에서 배운 것들

• 의사소통 : 말이 잘 통함. 

• 팀워크 : 우리 팀에서도 잘 어울리며 일할 수 있을까? → 답을 줘야. 상대방에 대한 존중, 팀원 신뢰, 공동 목적 추구, …

• 적극성, 긍정적 태도 : 팀에 에너지를 높여줄 수 있으면 무기력 < 미지근 < 열정적

보여주면 곤란한 것

• 거짓말, 숨기기 : 구라치다 걸리면….

• 소 귀에 경 읽기

• 쉽게 포기, 변명

• 자만심 : 조직을 해침. 입사하면 막내니 겸손해지자

• 소심함, 부정적 태도 : 맨날 끌고 다녀야함. 뭘 말하기 꺼려진다 → 그냥 같이 있고 싶지 않다.

• 준비 부족 : 자기소개 절면 못나보인다.

• 회사에 대한 얘기만 가득 → 현직자가 더 잘 안다. 적당히 쓰자.

• 금방 튈 거 같은데? → 이런 것도 거른다. ‘뽑아서 2~3년 가르쳤더니 이직하네?’ 느낌주면 안 된다. 

• 내 관점에서, 나에게 좋은 것만 잔뜩(내 성장을 위해 회사가 있는 건 아니다) → 나의 성장을 위해 지원을 했다? 회사와 같이 성장해야지 본인의 성장에만 관심이 있으면 이 친구를 왜 뽑아야 되지? 라는 생각이 든다.
