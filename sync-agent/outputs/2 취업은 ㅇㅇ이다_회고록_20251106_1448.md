🎴취업은 도박이다

혼자 준비하려고 하지마세요! 취업 컨설턴트, 프로젝트 컨설턴트, 멘토링, 현업자와의 커피챗, 전문가 리뷰 등등등 기회를 마구 활용해 봅시다!

• 서로(회사도, 지원자도) 베팅(vetting) 하는 거임.

• 결과가 나오기 전까지 짐작할 수 없음. → 입사해 봐야 알 수 있음 ㅠ

• 어떻게 할까? → 어느정도 포커페이스가 필요. 경험치를 쌓아야.

• 잭팟이 터질지도?! → 도박중독에 빠지진 맙시다.

🥘 취업은 요리다

• 좋은 재료가 맛을 결정

• 재료 = 기술 역량, 경험, 소프트 스킬, 태도, 관심사 etc

• 재료가 좋아도 조리가 잘못되면?

• 조리 = 자소서

• 플레이팅과 서비스가 후지면?

• 플레이팅, 서비스 = 면접

• 어떻게 할까? → 시간을 갖고 준비해야, 모든 단계에 정성을 들여야, 연습을 하고 간을 봐야(주변의 피드백, 멘토링)

🧩취업은 퍼즐이다

• 회사가 필요로 하는 조각 ~ 나라는, 내가 가진 조각, 내가 원하는 조각

• 서로 잘 맞으면? → 😻

• 역량 뿐만 아니라.. 회사(팀)과 나의 방향&성격도 잘 맞아야 함.

• 서로 조금씩 맞춰가야 함 → 보통은 신입이 맞춰야..

• 대기업엔 여러 모양의 퍼즐이 필요

• 스타트업엔 퍼즐이 적지만 서로 맞춰가기 편함

• 어떻게 할까? → 내가 가진 퍼즐이 잘 맞는 회사를 찾아 여기저기 시도해봐야.
