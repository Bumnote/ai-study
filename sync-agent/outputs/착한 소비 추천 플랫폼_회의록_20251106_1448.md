☑️ 1. 왜 만들려고 하는가?

✅ 1.1 문제 제기

• 시급한 과제로 떠오르는 환경 문제는 개인의 소비 습관과도 밀접한 연관이 있음

• 가격과 편의성을 넘어 탄소 배출, 재활용률, 친환경 인증 여부와 같은 지속가능성 요소도 소비의 고려대상에 포함되고 있음

• 하지만 자신이 사용하는 제품이 환경에 어떤 영향을 끼치는지 잘 모르는 경우 多

• ESG 경영이 기업의 필수 요소로 자리 잡고 있음에도 소비자에게 친환경 브랜드/제품 선택을 돕는 직관적인 플랫폼은 부족함

• 모든 친환경 제품이 실제로 환겨에 긍정적인 영향을 미치는 것은 아니기 때문에 소비자들이 진정한 친환경 제품을 구분하는 것이 중요해짐(그린 워싱)

• https://www.kcci.kr/46/?bmode=view&idx=108750352

✅ 1.2 문제 구체화 : 문제의 원인과 영향을 파악(Why → How)

• 사용자(혹은 시장)는 이 문제 때문에 어떤 불편을 겪는가?

• 이 문제는 얼마나 자주/광범위하게 발생하는가?

✅ 1.3 기존의 대안 조사

• 기존 쇼핑 플랫폼

• 환경 관련 데이터 사이트

☑️ 2. 프로젝트의 목적 (Project Purpose)

• 사용자의 소비 데이터를 분석해, 환경에 긍정적인 영향을 주는 대체 브랜드/제품 추천

• 제품 비교 시 가격, 리뷰 뿐만이 아니라 친환경 지수도 함께 고려할 수 있도록 지원

• 개인의 소비 습관을 분석하여, 환경 점수/탄소 절감 효과 시각화 제공

⇒ 소비자에게 더 쉽고 재미있게 착한 소비를 실천할 수 있는 플랫폼 제공
