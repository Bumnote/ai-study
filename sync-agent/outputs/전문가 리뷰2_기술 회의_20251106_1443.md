사전 질문

✅ 기술 및 현업 트렌드 관련

• 앞으로 3~5년 안에 지금 일하시는 분야에서 주목할 기술이나 지식이 있다면 어떤 걸까요? 신입 개발자 입장에서 미리 준비하면 좋을 게 있을까요?

✅ 실무 상황 관련

• 사용자 대시보드를 실제 서비스에 추가할 때, 유저 만족도나 이탈률에 어떤 변화가 있었는지 궁금합니다.

• FE, BE, AI가 같이 일할 때 자주 겪는 갈등은 어떤 게 있고, 그걸 풀기 위해 어떤 문서나 절차를 활용하시는지 궁금합니다.

• 팀에서는 코드 리뷰를 어떻게 진행하시나요? 좋은 리뷰 문화를 만들기 위해 신경 쓰는 부분이나, 리뷰할 때 꼭 보는 포인트가 있는지 궁금합니다.

• API 성능 테스트 도구(JMeter, nGrinder, k6 등)를 선택할 때 어떤 기준으로 고르시나요? 실무에서 각각의 장단점은 어떻게 느껴지셨는지 궁금합니다.

• 테스트 코드를 작성할 때, 어떤 걸 먼저 챙기시는지 궁금합니다. (예: 단위테스트, 통합테스트, E2E 중 우선순위)

• A/B 테스트를 직접 운영해보셨다면, 기능 개선을 위한 실험을 어떻게 설계하고 실행하셨는지 궁금합니다.

• 유저 행동 데이터를 모을 때, 어떤 로그 수집/분석 도구를 주로 사용하시고, 어떻게 운영하면 효율적인지 궁금합니다.

✅ 취업 및 포트폴리오

• 신입 개발자의 포트폴리오를 볼 때, 어떤 부분이 인상 깊게 느끼시는지 궁금합니다. (예: 기술 선택 이유, 문제 해결 방식, 테스트 코드 유무 등)

• 이런 프로젝트 경험은 꼭 있었으면 한다거나 자주 보이는 아쉬운 포인트가 있으셨나요?

✅ 함께 일하고 싶은 사람

• 기술적인 실력 외에, 이 친구랑은 꼭 같이 일해보고 싶다고 느끼게 만드는 태도나 역량이 있었는지 궁금합니다.

• 개발자에게 커뮤니케이션 능력이 중요하다고 하는데, 현업에서 체감하시는 좋은 커뮤니케이션이란 구체적으로 어떤 모습인가요?
