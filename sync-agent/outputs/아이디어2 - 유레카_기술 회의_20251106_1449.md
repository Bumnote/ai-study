☑️ 1. 왜 만들려고 하는가?

✅ 1.1 문제 제기

수많은 예비 개발자와 학생들은 포트폴리오 프로젝트를 시작하는 첫 단계, 즉 '의미 있고 나에게 맞는 주제를 선정하는 단계'에서 가장 큰 어려움을 겪는다. 이 첫 번째 장벽을 넘지 못해 프로젝트를 시작조차 못 하거나, 결국 모두가 만드는 진부한 프로젝트를 선택하여 차별화된 경쟁력을 갖추지 못하는 문제가 만연해 있다.

✅ 1.2 문제 구체화 : 문제의 원인과 영향을 파악(Why → How)

• 왜 이런 문제가 발생했는가?

• 사용자(혹은 시장)는 이 문제 때문에 어떤 불편을 겪는가?

• 이 문제는 얼마나 자주/광범위하게 발생하는가?

✅ 1.3 기존의 대안 조사

• 블로그 및 유튜브: '토이 프로젝트 추천' 등의 키워드로 검색된 정적인 콘텐츠. 개인화가 불가능하고 정보가 오래되었을 확률이 높다.

• 깃허브 리스트: Awesome-Project-Ideas 등 큐레이션 된 목록. 아이디어만 나열되어 있을 뿐, 구체적인 기획 방향이나 데이터 소스 정보가 없다.

• ChatGPT 등 범용 AI: 아이디어를 생성해주지만, 사용자의 기술 수준을 모르고 최신 개발 트렌드를 실시간으로 반영하지 못하며, 기획을 위한 구조화된 질문을 사용자가 직접 해야 하는 어려움이 있다.

☑️ 2. 프로젝트의 목적 (Project Purpose)

본 프로젝트의 목적은 아이디어 탐색의 막막함을 해결하고, 개인의 관심사, 기술 수준, 목표에 최적화된 프로젝트 아이디어를 동적으로 추천하는 것이다. 나아가 아이디어 생성에 그치지 않고, 기획의 초기 단계를 자동화하여 누구나 쉽게 자신만의 독창적인 프로젝트를 시작할 수 있도록 진입 장벽을 낮추는 것을 목표로 한다.

☑️ 3. 시장 조사 및 경쟁 분석

✅ 3.1 해야 할 조사

• 유사 서비스 조사

• 경쟁사가 해결하지 못한 Pain Point 정리

✅ 3.2 경쟁사 비교 분석 (SWOT 분석)

• 강점 (Strength)

• 약점 (Weakness)

• 기회 (Opportunity)

• 위협 (Threat)

• 고객 인터뷰 또는 설문조사

☑️ 4. 부록

• 관련 연구: 추천 시스템 알고리즘, 자연어 처리를 통한 텍스트 마이닝, LLM을 활용한 텍스트 생성 관련 논문.

• 활용 데이터 소스: GitHub API, arXiv API, 공공데이터포털 API 리스트, 기술 뉴스 사이트(크롤링 대상), Google AI Platform (Gemini API) 등.

• 기대 효과: 사용자들의 프로젝트 중도 포기율 감소, 포트폴리오 품질 상향 평준화, 신기술 학습 촉진.
