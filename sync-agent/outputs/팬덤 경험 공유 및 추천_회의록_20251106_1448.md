☑️ 1. 왜 만들려고 하는가?

✅ 1.1 문제 제기

• 영화·드라마 팬덤 확장: K-드라마, K-무비 세계적으로 인기 많아짐. 팬들은 작품 속 공간을 실제로 경험하고 싶어 함.

• 정보 분산: 촬영지 정보가 블로그, 기사, 유튜브 등 여기저기 흩어져 있어서 한눈에 보기 힘듦.

• 코스화 부족: 개별 장소는 찾아도, 작품 기반·테마 기반으로 여행 코스 설계 서비스 없음.

• 실시간성 한계: 촬영지가 폐쇄되거나 변한 경우도 많지만, 현장 상태를 즉시 알 방법 없음.

✅ 1.2 문제 구체화 : 문제의 원인과 영향을 파악(Why → How)

• 왜 이런 문제가 발생했는가?

• 사용자(혹은 시장)는 이 문제 때문에 어떤 불편을 겪는가?

• 이 문제는 얼마나 자주/광범위하게 발생하는가?

☑️ 2. 프로젝트의 목적 (Project Purpose)

• 영화·드라마 촬영지 기반 위치 정보 + 팬 경험 공유 플랫폼 구축.

• 사용자가 작품별·장르별·지역별로 촬영지를 검색 → 맞춤형 여행 코스 추천.

• 팬들이 현장 방문 시 사진/후기/실시간 상태 공유 → 집단 지식 DB 형성.

• 단순 지도 정보 제공이 아니라, 팬덤 커뮤니티 + 여행 경험 결합이 목적.

• 나아가 관광 산업(지자체·여행사)과 연계 가능 → 문화관광 활성화에 기여.
