☑️ 1. 왜 만들려고 하는가?

✅ 1.1 문제 제기

• 언어 학습자는 실제 현지 콘텐츠를 접하기 어렵고, 교재에만 의존

• 기존 뉴스 서비스는 언어 학습자의 수준을 고려하지 않고 원문 그대로 제공

✅ 1.2 문제 구체화 : 문제의 원인과 영향을 파악(Why → How)

• 왜 이런 문제가 발생했는가?

• 사용자(혹은 시장)는 이 문제 때문에 어떤 불편을 겪는가?

• 이 문제는 얼마나 자주/광범위하게 발생하는가?

✅ 1.3 기존의 대안 조사

• Google News, 네이버 뉴스, BBC 등 글로벌 뉴스 플랫폼 → 언어 학습 관점 부족

• Duolingo, LingQ 등 언어 학습 앱 → 실제 뉴스/시사 매락 결여

• 파파고, DeepL 번역 → 직역 중심, 난이도 조절 불가

☑️ 2. 프로젝트의 목적 (Project Purpose)

• 언어 학습자의 수준과 관심사에 맞춘 맞춤형 글로벌 뉴스 큐레이션 서비스 제공

• 뉴스를 통한 학습 = 언어 학습 + 세계 이해

• 사용자별 학습 데이터 및 개인화 추천 고도화

• 글로벌 사회, 언어 교육 양쪽 시장에서 확장 가능

☑️ 3. 시장 조사 및 경쟁 분석

✅ 3.1 해야 할 조사

• 유사 서비스 조사

• 경쟁사가 해결하지 못한 Pain Point 정리

✅ 3.2 경쟁사 비교 분석 (SWOT 분석)

• 강점 (Strength)

• 약점 (Weakness)

• 기회 (Opportunity)

• 위협 (Threat)

• 고객 인터뷰 또는 설문조사

☑️ 4. 부록

• 참고 API: Google News API, NewsAPI.org, GDELT.

• 기술 스택:

• 잠재적 수익 모델: 구독(프리미엄 학습 기능), 광고(언어 학습/글로벌 교육 관련).

• 추가적으로, 시간이 된다면 기사 번역하기 기능을 추가해도 좋을 것 같습니다. + AI를 통한 교정
